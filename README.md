# BTC Mining ROI Simulator

An investment analysis website for ASIC mining. Enter device parameters, capital, electricity cost, and market assumptions to calculate break-even month and end-of-window profit.

Uses Power Law regression for BTC price and network hashrate projection. Live data is fetched from CoinGecko and mempool.space.

Supports Turkish and English interface.
